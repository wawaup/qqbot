# 回国代理教程

人在国外，访问 `wzyp.cn`、`catfk.com` 以及国内站点时，先连到阿里云（`alpu.asia`），再由这台机访问国内网络。和常见翻墙相反：国内走代理，国外直连。

服务端用官方 [Hysteria2](https://hysteria.network/)，不要用 sing-box。客户端用 Hiddify、Clash Verge 或 Clash Meta，导入同一条 Clash 订阅即可。

qqbot 也跑在这台机上，代理只多占 **UDP 443**，不改 bot、不抢网站的 TCP 443。

## 流量怎么走

```
电脑 / 手机（国外）
    → Hiddify / Clash Verge / Clash Meta
    → 订阅拿到节点
    → 阿里云 Hysteria2（UDP 443）
    → 国内网站
```

| 端口 | 进程 | 用途 |
|---|---|---|
| TCP 443 | nginx | 网站 `alpu.asia` + 订阅文件 |
| UDP 443 | hysteria | 回国代理 |
| 出站 | qqbot | 爬店铺、发 QQ 消息，不占入站端口 |

`ignoreClientBandwidth: true`，用 BBR，避免把 2C2G 的国际带宽打满拖死 bot。

## 分流规则

写在 `templates/clash.yaml`，按从上到下匹配：

1. 局域网直连
2. **`catfk.com`、`wzyp.cn` 及其子域强制走回国**
3. 国内域名：`RULE-SET`（cn / apple-cn / google-cn）
4. 国内 IP：`GEOIP,CN`
5. 其余直连（Google、YouTube 等走当地网络）

DNS 里 `nameserver-policy` 必须把规则集和域名拆开写。`rule-set:` 后面只能跟规则集名字，不能写成 `'rule-set:cn,+.catfk.com'`，否则客户端会去找名为 `+.catfk.com` 的规则集。

## 部署前准备

1. 域名已解析到这台 ECS（当前是 `alpu.asia` → `120.27.141.92`），nginx 已有 Let's Encrypt 证书。
2. 阿里云安全组放行 **UDP 443**。TCP 443 本来就有，不要改。
3. 确认网站没开 HTTP/3（QUIC）。Hysteria2 和 HTTP/3 不能同时占 UDP 443。`ss -ulnp | grep 443` 部署前应为空。
4. 本机已有 SSH 密钥能登录 `root@120.27.141.92`。

## 服务器安装

在仓库里：

```bash
cd proxy-setup
cp secrets.env.example secrets.env
# 编辑 secrets.env：HY2_PASSWORD、OBFS_PASSWORD、SUB_TOKEN 都改成随机长字符串
```

`SUB_TOKEN` 是订阅 URL 路径，等同于密码，不要用简单词。

国外下二进制更快，再传到服务器：

```bash
curl -fL -o /tmp/hysteria-linux-amd64 \
  https://github.com/apernet/hysteria/releases/download/app%2Fv2.12.2/hysteria-linux-amd64

scp -r proxy-setup root@120.27.141.92:/root/proxy-setup
scp /tmp/hysteria-linux-amd64 root@120.27.141.92:/tmp/hysteria
scp proxy-setup/secrets.env root@120.27.141.92:/root/proxy-setup/secrets.env

ssh root@120.27.141.92 'HY2_BIN_SRC=/tmp/hysteria bash /root/proxy-setup/deploy.sh'
```

脚本会：

- 安装 `/usr/local/bin/hysteria`
- 复用 `/etc/letsencrypt/live/alpu.asia/` 证书
- 写 systemd：`alpu-proxy.service`
- 在 nginx 里挂秘密路径 `/s/<SUB_TOKEN>/`
- 证书续期后自动重启代理

装完打印的订阅 URL 保存好，不要发到群里。

手动检查 nginx 的 **正在使用的** 站点文件（不要改 `.bak-*` 备份）里有没有：

```nginx
include /etc/nginx/snippets/alpu-proxy-sub.conf;
```

应放在 `server_name alpu.asia` 附近、`location /` 之前。`^~ /s/TOKEN/` 比 `location /` 优先，订阅不会进后面的反代。

## 客户端

同一条订阅：

`https://alpu.asia/s/<SUB_TOKEN>/clash.yaml`

| 设备 | App | 导入 |
|---|---|---|
| 电脑 | Clash Verge | 订阅 → 新建远程配置 |
| 安卓 | Clash Meta | + → URL 导入 |
| iPhone | Hiddify | + → 从 URL 添加 |

必须开 **TUN / VPN 模式**，否则只有浏览器走代理，微信等 App 不走。

优先用节点「回国-Hysteria2」。改完规则后要**删除旧订阅再导入**，只点更新有时会继续用本地缓存。

## 验证

```bash
systemctl status alpu-proxy qqbot nginx
ss -ulnp | grep 443          # hysteria 占用 UDP 443
ss -tlnp | grep ':443 '      # nginx 占用 TCP 443
curl -sI https://alpu.asia/s/<SUB_TOKEN>/clash.yaml
journalctl -u alpu-proxy -f
```

网站 `https://alpu.asia` 应和以前一样能打开。

## 常见问题

**Clash Meta：`load Geosite data error fail to decode`**  
本配置不用 `GEOSITE`，改用 `rule-providers` 拉 yaml 规则集。若仍报错，到 App 设置里更新或删除本地 `GeoSite.dat`，然后删订阅再导入。

**`not found rule-set +.catfk.com`**  
`nameserver-policy` 把 `rule-set:cn` 和 `+.catfk.com` 写在同一个 key 里了。规则集、域名必须分成两个 key，见 `templates/clash.yaml`。

**连不上节点**  
先看阿里云安全组是否放行 UDP 443。公司/酒店若禁 UDP，Hysteria2 会失败。

**订阅 403**  
站点对无浏览器 UA 可能拦截。订阅用了 `location ^~`，应能绕开；若仍 403，把 include 挪到 UA 拦截规则前面。

**UDP 443 被占用**  
关掉 nginx/caddy 的 HTTP/3，或把 `HY2_PORT` 改成 `8443` 后重跑脚本，并放行 UDP 8443。

**国际带宽很慢**  
包年 ECS 国际口通常只有几 Mbps。聊天、网页、店铺没问题，不要拿来看 4K。

阿里云大陆机当代理可能违反服务条款。这是个人自用，不要把订阅分给别人。

## 强制走回国的域名

改 `templates/clash.yaml` 两处，然后在服务器上重新渲染订阅（或再跑一次 `deploy.sh`）：

- `rules` 里加 `DOMAIN-SUFFIX,<域名>,国内`
- `dns.nameserver-policy` 里加独立 key `'+. <域名>'`（注意是单独一条，不要拼进 `rule-set:`）

当前已强制：`catfk.com`、`wzyp.cn`。

## 卸载

```bash
systemctl disable --now alpu-proxy
rm -f /etc/systemd/system/alpu-proxy.service
rm -f /etc/nginx/snippets/alpu-proxy-sub.conf
rm -f /etc/sysctl.d/99-alpu-proxy.conf
rm -f /usr/local/bin/hysteria
rm -rf /opt/alpu-proxy
# 从 nginx 站点配置里删掉 include alpu-proxy-sub.conf 那一行
nginx -t && systemctl reload nginx
```
